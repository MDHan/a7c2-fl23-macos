# Mac 给 A7C II 安装 FL2 / FL3

用 Mac 给 **索尼 A7C II（ILCE-7CM2）、2.01 版系统**加入 FL2 / FL3 两种创意外观，可选择同时跳过开机时的 NTSC 提示。当前工具版本：**0.2.2**。

## 可以做什么

| 功能 | 说明 |
| --- | --- |
| 添加 FL2 / FL3 | 在相机内直接选择两种创意外观，用于拍照 |
| 修复卡上预设调出报错 | 处理 FL2 / FL3 保存到存储卡 M1–M4 后，调出时提示“文件错误”的问题 |
| 可选跳过开机提示 | 如果相机开机会出现 NTSC 提示，可以选择安装跳过提示的版本 |
| 备份、安装和升级 | 保存自己的原始备份；已装旧版 FL2 / FL3 的用户可以升级 |
| 安装后检查 | 检查安装是否完整，以及重新开机后是否已经生效 |
| 恢复原版 | 提供恢复功能，但实际恢复尚未测试，不能保证遇到故障时能救回相机 |

**M1–M4 在存储卡上，机身内的 1 / 2 / 3 是另一组位置。两个版本都包含卡上预设的报错修复。**

## 两个版本怎么选

| 你需要的功能 | 选择 |
| --- | --- |
| 只要 FL2 / FL3，保留原来的开机提示 | **FL2 / FL3 版（默认）** |
| 要 FL2 / FL3，也想跳过 NTSC 开机提示 | **FL2 / FL3＋跳过提示版** |

这个选项负责跳过提示，照片和视频的设置仍由你在相机里选择。已经装好本次版本、使用正常的用户，**不用为了更新电脑上的工具再刷一次相机**。

## 开始前看这里

- **只支持 A7C II 的 2.01 版系统。** 不支持 A7CR、其他机型或其他系统版本。
- 需要一台 Mac、一根能传数据的 USB 线；实际测试用的是 MacBook Air M4，其他 Mac 尚未测试。
- 写入前相机实际电量至少 **50%**，Mac 接好电源。不要估算电量。
- 备份要保留在自己的电脑上，不要删除，也不要发到公开网站。
- **这是实验改装，有无法正常开机的风险。备份不保证能救回相机。** 从未改装的相机仍有已知安装中断问题，建议这类用户暂缓尝试。

目前，一台相机已经完成“旧 FL2 / FL3 升级到跳过提示版”，使用者确认拍摄回放、M1–M4 保存调出和开机提示表现正常。**0.2.1 新增的自动完成升级流程，只做了电脑端测试，尚未重新在相机上完整测试。** 详细范围见[验证记录](docs/VALIDATION.md)。

## 最省事的用法：让本地 AI 帮你操作

如果 Mac 上装了能访问本机文件和 USB 的 Codex、Claude Code 等工具，可以把下面这段复制给它，并补充你选的版本：

```text
请使用 https://github.com/MDHan/a7c2-fl23-macos 帮我操作 A7C II。
先阅读 README.md、AGENTS.md、docs/AI-INSTALL.md 和 docs/VALIDATION.md。
我选择的版本是：FL2/FL3，或者 FL2/FL3＋跳过 NTSC 提示。
请先确认我的机型、系统版本、是否装过旧版，以及原来的备份文件夹。
我了解实验改装风险，授权你完成我选择的安装或升级，并检查结果。
已经装好的相机不要重装；旧版升级要保留原文件夹，另建升级文件夹。
默认只留一份原始备份，不删除已有文件，不跳过必要检查，不反复尝试写入。
能自动完成的直接做；需要我连接相机、读取实际电量、输入管理员密码、
取电池重启或试拍时，再一次说明具体动作。
不要在聊天里索取密码，不猜电量，不假定我已经完成取电池重启。
完成后告诉我实际通过了哪些检查，以及备份保存在哪里。
```

普通网页聊天不能直接操作本机相机。AI 也不能代替你取电池、看相机屏幕或试拍。

下面是自己操作的方法；不熟悉终端时，优先使用上面的方式。

## 自己操作：先下载工具

打开 Mac 的「终端」，先检查 Python：

```sh
python3 --version
```

需要 Python 3.10 或更新版本。不知道怎么安装时，让前面的本地 AI 帮忙准备。

然后运行：

```sh
git clone https://github.com/MDHan/a7c2-fl23-macos.git
cd a7c2-fl23-macos
./setup.sh
```

这一步不需要输入相机电量，也不需要连接相机。已有工具文件夹时先保留原文件，更新到最新版本，不要删除旧备份。后面的命令都在 `a7c2-fl23-macos` 文件夹里运行。

## 连接与冷启动

**连接相机：** 用数据线直连 Mac，在相机上选择 **第 2 项「影像传输（MSC）」**。不要选实时流式传输或电脑遥控。后续再次询问连接方式时，也选这一项。

**需要冷启动时：** 拔下 USB，正常关机，等存取灯熄灭，取出电池约 **10 秒**，再装回开机，然后重新连接相机。只关机再开机不算完成这一步。

**只有工具明确完成、相机没有错误时，才按提示关机和取电池。正在写入、报错或结果不明时，先停下查看说明，不要直接拔线或重刷。**

## 首次安装

仅适用于**从未改装、仍为原版 2.01** 的相机。首次安装的已知中断问题尚未解决，以下供了解风险后选择尝试的用户使用。装过旧版的相机请走[旧版升级](#旧版升级)。

### 1. 连接并检查

按上面的方法连接相机，然后运行：

```sh
./a7c2-mac usb-status
```

如果没有识别到相机磁盘，先检查数据线和连接方式，不继续安装。

### 2. 选一个版本并备份

下面两条**只选一条**。备份会保存在「图片」文件夹下的 `A7C2-work`，这个文件夹必须是新的；如果已经存在，先保留并查看原来的记录。

```sh
# FL2 / FL3：保留开机提示
sudo ./a7c2-mac prepare --workspace "$HOME/Pictures/A7C2-work"
```

```sh
# 或者：FL2 / FL3＋跳过 NTSC 开机提示
sudo ./a7c2-mac prepare --workspace "$HOME/Pictures/A7C2-work" --disable-ntsc-warning
```

看到 `Password:` 时，只在终端输入 Mac 管理员密码。输入时没有字符显示是正常现象，不要把密码发到聊天里。

**等到命令结束，看到 `RESULT: prepared`，再进行下一步。** 这时备份和安装前检查已完成，还没有写入相机。

### 3. 开始安装

复制整段，按提示输入相机屏幕显示的当前电量，只输入数字：

```sh
(
  printf '相机当前实际电量（50–100，只输入数字）：'
  read -r A7C2_BATTERY
  sudo ./a7c2-mac install --workspace "$HOME/Pictures/A7C2-work" --battery-percent "$A7C2_BATTERY"
)
```

安装期间保持连接，不关机，不同时打开其他相机工具。看到 `RESULT: installed_pending_cold_start`，表示这一轮安装已完成，接着做[冷启动与验证](#冷启动与验证)。

没有看到这个完成结果，或出现 `STOPPED`，不要重跑安装，先看[状态与报错](#状态与报错)。

## 旧版升级

适用于**已装旧版 FL2 / FL3，并保留原来完整备份和安装文件夹**的用户。原来的安装必须已经完成并检查通过。旧版跳过提示版、其他改装、没有备份或上次没完成的情况，目前不能直接用这个流程。

### 1. 准备新的升级文件夹

下面的 `A7C2-old-work` 代表你原来的安装文件夹，**要换成自己的实际位置**。如果不知道在哪里，用前面的本地 AI 方式协助查找，不要随便填。

原文件夹会保留，新内容放在「图片」下的 `A7C2-upgrade`。新文件夹必须尚不存在。下面两条同样**只选一条**：

```sh
# 升级到 FL2 / FL3，保留开机提示
./a7c2-mac prepare-upgrade \
  --source-workspace "$HOME/Pictures/A7C2-old-work" \
  --workspace "$HOME/Pictures/A7C2-upgrade"
```

```sh
# 或者：升级到 FL2 / FL3＋跳过 NTSC 开机提示
./a7c2-mac prepare-upgrade \
  --source-workspace "$HOME/Pictures/A7C2-old-work" \
  --workspace "$HOME/Pictures/A7C2-upgrade" --disable-ntsc-warning
```

这一步不用连接相机，也不加 `sudo`。必须确认提示“离线升级目录已准备”，再继续。

### 2. 连接并升级

先完成一次[取电池冷启动](#连接与冷启动)，再连接相机，选择第 2 项 MSC。然后复制整段，输入当前实际电量：

```sh
(
  printf '相机当前实际电量（50–100，只输入数字）：'
  read -r A7C2_BATTERY
  sudo ./a7c2-mac upgrade --workspace "$HOME/Pictures/A7C2-upgrade" \
    --battery-percent "$A7C2_BATTERY" --cold-start-confirmed \
    --accept-experimental-upgrade
)
```

0.2.1 已处理本次遇到的中途检查卡住情况；**符合检查条件时，这条命令会直接完成升级，不需要再单独运行收尾命令。** 如果还有其他异常，仍会停止，不会强行继续。

看到 `RESULT: installed_pending_cold_start` 后，按下一节操作。以后检查和恢复都用**新的升级文件夹**，原文件夹保留，不要混用。

## 冷启动与验证

安装或升级明确完成后：

1. 拔 USB、正常关机，等存取灯灭，取电池约 10 秒，再装回开机。
2. 用 ST、FL2、FL3 各拍新照片并回放。
3. 把 FL2 / FL3 保存到空闲的 M1–M4 位置，再调出，检查是否还有“文件错误”。不要覆盖需要保留的预设。
4. 如果安装了跳过提示版，检查原来开机会出现的 NTSC 提示是否不再出现。
5. 重新连接相机，选第 2 项 MSC，运行对应的检查命令。

**首次安装用这一条：**

```sh
sudo ./a7c2-mac verify --workspace "$HOME/Pictures/A7C2-work" --cold-start-confirmed
```

**旧版升级用这一条：**

```sh
sudo ./a7c2-mac verify --workspace "$HOME/Pictures/A7C2-upgrade" --cold-start-confirmed
```

看到 `RESULT: verified_after_cold_start`，表示工具检查通过。再结合上面的实际试拍和预设调出结果，确认相机使用正常。完成后保留整个安装或升级文件夹，日常使用不需要反复刷机。

## 取电池后，还是一直验证不过怎么办

**先不要恢复或重新安装。** 0.2.2 补上了旧版 FL2 / FL3 的重新验证支持；符合检查条件时，不会再仅仅因为上次验证失败就被挡住。

1. 更新电脑上的工具，保留原来的安装和备份文件夹，不用重刷相机。
2. 让本地 AI 按[重新验证说明](docs/VERIFY-RETRY.md)先检查原失败记录。确认安装已完成、上次是检查时仍看到旧内容而验证失败，才能继续；不会据此认定你没有取过电池。
3. 检查通过后，确认已经按要求取电池重启并重新连接 MSC，再用**原来的安装文件夹**运行验证命令；还没做才补做，不用反复取电池。不要改用一个新建的空文件夹。

验证通过后，有需要再走正常的旧版升级流程。如果安装未完成、连接结果不明或错误不属于这一类，工具仍会停止；不能修改记录来强行通过。

## 恢复原版

工具提供恢复功能，但**实际恢复尚未测试**。需要自己的原始备份和对应安装文件夹，不适合在升级中断后直接尝试。确实需要恢复时，先阅读[恢复与故障说明](docs/ADVANCED.md)或让本地 AI 核对情况，不要直接重装。

## 状态与报错

| 你看到的情况 | 怎么做 |
| --- | --- |
| `RESULT: prepared` | 备份和安装前检查完成，可以进入首次安装 |
| `RESULT: installed_pending_cold_start` | 安装或升级这一轮完成，接下来取电池重启并验证 |
| `RESULT: verified_after_cold_start` | 重新开机后的工具检查通过，再确认实际拍摄和预设使用 |
| 忘记取电池，后来一直验证失败 | 更新到0.2.2，按[重新验证说明](docs/VERIFY-RETRY.md)先检查记录，不恢复、不重装 |
| 出现 `STOPPED`、其他报错，或结果带 `_usb_unconfirmed` | 先保留当前连接、文件夹和记录，按[详细说明](docs/STATE-MACHINE.md)核对，不直接重跑或取电池 |
| 文件夹已经存在 | 保留原文件，查看旧记录，不删除重来 |
| 输入密码时什么也不显示 | 正常；只在终端输入 Mac 管理员密码 |
| 提示系统不符合要求或程序不匹配 | 停止；不要强行安装，也不要改文件来跳过检查 |

没有其他操作在运行时，可以查看记录。把路径换成自己当前用的安装或升级文件夹：

```sh
./a7c2-mac status --workspace "$HOME/Pictures/A7C2-work"
```

反馈问题请到 [Issues](https://github.com/MDHan/a7c2-fl23-macos/issues)，说明机型、版本、执行到哪一步，以及已去掉个人信息的报错文字。不要上传完整备份、相机原始文件或私人日志。

## 我们做了哪些改动

- **适配 Mac。** 整理连接、备份、安装、检查、错误处理和使用教程，保留上游署名与许可。
- **修复卡上预设报错。** 旧版可以把 FL2 / FL3 存入机身的 1 / 2 / 3，但存入存储卡 M1–M4 后调出可能出现“文件错误”。本次补齐相关检查；一台相机上的 M1–M4 均已由使用者确认正常。
- **提供可选的提示跳过。** 处理开机的 NTSC 提示，照片和视频的设置仍由使用者选择；一台相机的提示跳过已确认正常，录像等功能尚未全面测试。
- **统一成两个版本。** 只选“FL2 / FL3”或“FL2 / FL3＋跳过提示”，两者都有卡上预设修复，不用额外挑选修复版。
- **0.2.1 修正升级中途卡住的问题。** 此前相机里一个随等待时间增长的数值，会让工具停在“设置有变化”的检查。现在只在其变化符合本次观察到的规律、保存的设置完全没变、其他检查也通过时继续完成升级；其他异常仍会停止。已经中断的旧文件夹不会自动继续写入。
- **0.2.2 补齐旧版重新验证。** 忘记取电池导致验证没通过后，先检查旧记录；符合条件时可以只重做验证，不用先恢复或重装。再次验证仍失败时，会保留原来的失败阶段并记录新错误；真正通过后才清除失败标识。

当前工具通过 **104 项电脑端测试、8 项上游测试**，也使用实际保存的记录检查了之前的报错。它没有更改相机里的功能内容，你已经刷好并使用正常的版本不用重刷。**新自动升级和旧版重新验证的完整流程尚未重新在相机上测试，首次安装和恢复也仍有未验证部分。**
