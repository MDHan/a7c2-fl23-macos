# 给 Codex / Claude Code 等本地 AI 的安装指南

[返回简明教程](../README.md) · [验证范围](VALIDATION.md) · [故障与恢复](ADVANCED.md)

需要能够在用户自己的 Mac 上读写文件、执行终端命令的 AI 环境。云端容器、远程 Linux 和纯网页聊天不能直接操作这台 Mac 的 USB 相机。AI 能否自动执行 sudo 取决于当前环境；不要承诺全程无人值守。

## 用户复制的任务

```text
请使用 https://github.com/MDHan/a7c2-fl23-macos 帮我安装 FL2/FL3。
先阅读 README.md、AGENTS.md、docs/AI-INSTALL.md 和 docs/VALIDATION.md。
我了解实验风险，授权完成本机环境准备、单份备份、预检查、安装、验证。
请先检查已有安装和工作目录，已安装就只验证。能自动做的直接做。
只有相机连接/MSC选择、实际电量、系统授权、取电池和试拍需要我配合时再提示。
不要问我要密码，不猜电量，不绕过校验，不自动重跑失败写入。
最终报告实际通过的项目，以及本机备份所在位置。
```

## 执行顺序

### 安装内容选择

面向用户只有两种：默认 FL2/FL3（内置 M1–M4 修复、保留提示），或显式加 `--disable-ntsc-warning` 的 FL2/FL3＋跳过 NTSC 提示（同样内置修复）。新目录分别保存 `["fl23", "mr_card_compat"]` 或额外包含 `"no_ntsc_notice_v2"`；安装、7/9区域验证及恢复自动沿用。

原版 2.01 使用下文首次安装流程，固定完整指纹校验针对公共固件版本，不是针对某台机身。已安装旧版 FL2/FL3 且有已完成冷启动验证的工作目录时，按 [UPGRADE.md](UPGRADE.md) 创建独立升级目录；不要重复首次安装或手改状态。旧版 NTSC 的追加升级尚不支持。专项 diagnose/finish-install 只处理旧版明确停止点。

0.2.1 新执行的升级已包含本次时间相关当前字段的有界设置检查，保存设置必须逐项不变，通过后在同一次 `upgrade` 中完成原有WBI，无需额外收尾命令。此自动全流程只经离线验证，未重新完整上机测试。若已有目录在程序读回后停止，保留证据按 [UPGRADE-FINISH.md](UPGRADE-FINISH.md) 审查，不能重跑已有写入尝试。旧目录的 `finish-upgrade` 及额外时间例外仍须使用者明确选择；不扩大到首次安装。

0.2.2 为旧版默认FL23和新版两类提供[受控只读重验](VERIFY-RETRY.md)。`needs_review / failed_action=verify` 不必一律拒绝：先离线校验失败阶段、精确错误、原始报告和正常退出，再由用户确认实际取电池重启，符合条件后执行原有verify。Issue #6的公开模式已覆盖；不凭运行时间认定用户没取电池。新验证仍逐项检查完整程序、参数和运行内容，失败不算通过、不修改原阶段冒充成功。通过后才可正常prepare-upgrade；不先restore或重新install。

### 1. 确认条件与已有状态

读取根目录 `AGENTS.md`。先确认：

- 当前执行环境为用户本机 macOS，检查 `sw_vers`、`uname -m`。
- 相机为 ILCE-7CM2，原版 2.01；让用户提供无法读取的屏幕信息。最终以工具的机身身份和完整 AP/CP 指纹核验为准，不能把用户口述版本代替指纹检查。
- 已验证环境为 MacBook Air M4、macOS 27.2、Python 3.12.14；Python 代码门槛为3.10+。其他 Mac/系统尚未实测，不自动为安装而升级系统或相机固件。
- 是否已装过 FL2/FL3、是否有已有工作目录。用户给出目录后先 `status`。不要全盘搜集私人文件，不要删除旧目录来“重新开始”。
- 若本机就是本项目已验证的机身，也不能把此前的电量当作现在的实际电量。

### 2. 自动准备环境

选择一个明确的项目目录。已有仓库先检查改动，保留用户修改；新项目可 clone。本机检查 Python 3.10+ 与 Git，运行 `./setup.sh` 和 `./a7c2-mac check`，不用 sudo。

若缺 Python，先找可用的已安装解释器，不覆盖系统 Python。需要下载运行时时核对官方来源；把环境配置变化告诉用户，遵守所在 AI 工具的权限要求。不要求用户为本项目关闭 SIP、绕过文件访问限制或设置免密码 sudo。

工作目录使用仓库外的新路径，父目录须存在。例如 `~/Pictures/A7C2-work`。默认只保留 `original/` 中的一份备份，**不要主动加 `--backup-copy`**。已有目录先检查状态，不能覆盖、拼接不同机身数据或伪造身份。

### 3. 连接检查

让用户用数据线直连相机，在连接界面选择 **2 影像传输（MSC）**。不选 USB流式传输、MTP 或电脑遥控。

运行 `./a7c2-mac usb-status`。这个命令只读取 macOS 的 USB/磁盘信息。必须通过后再接管 USB。磁盘编号由程序动态检查，不把示例中的 disk4/disk5 当作通用编号。

### 4. 备份与预检查

用户已授权安装时，可以直接运行：

```sh
sudo ./a7c2-mac prepare --workspace "$HOME/Pictures/A7C2-work"
```

该步骤会进入服务模式、读取程序/设置并运行临时诊断模块，尚未写入固件或保存设置。等程序结束，检查实际退出码和最新状态，不凭“好了”或某条中间输出判断完成。

若 AI 环境可直接获得管理员权限，正常执行即可；若 `sudo -n` 表明需要密码，提供**一条已经准备好的完整命令**，请用户在其终端启动并输入密码。随后由 AI 继续读取工作目录中的结果，不必要求用户反复复制完整日志。不要通过聊天收集密码，也不要绕过权限拒绝。

### 5. 安装

在 `prepared` 且本机身备份核验通过后，取得用户刚读出的实际电量，至少50%。已有授权无需每一步重新询问许可，但缺失的实际电量必须询问，不能用示例数字替代。

```sh
sudo ./a7c2-mac install --workspace "$HOME/Pictures/A7C2-work" --battery-percent ACTUAL_PERCENT
```

将 `ACTUAL_PERCENT` 替换为刚取得的实际值。监督进程及工作目录日志；写入中不要并行启动其他相机工具、拔线、复位USB或要求关机。若出现连接选择界面，提示用户选第2项MSC。

### 6. 断电与验证

正常完成 `installed_pending_cold_start` 后，提示用户拔 USB、正常关机、等存取灯灭、取电池约10秒再装回开机。**这是物理操作，AI不能自动完成，也不能假定已经发生。**

收到用户实际完成的确认后，检查重新连接的MSC身份，再运行：

```sh
sudo ./a7c2-mac verify --workspace "$HOME/Pictures/A7C2-work" --cold-start-confirmed
```

请用户查看FL2/FL3菜单，分别重设两个外观，用ST/FL2/FL3各拍一张新照片并回放。电脑端通过和人工拍摄通过分别记录，不能互相代替。

## 已安装机身

已有 `installed_pending_cold_start` 或 `verified_after_cold_start` 工作目录时，按实际冷启动状态执行 `verify`；显式选择更新到两类新版本时使用独立升级流程。不要再次 `prepare` 或 `install`。没有原始备份且机身已改装时，停止并说明；不能拿其他机身的备份补齐。

## 出错时

- 0.2.3 对首次安装进入服务模式前的精确 `0336` 超时增加 `install --retry-service-entry`，仅当用户明确选择重试时按 [INSTALL-RETRY.md](INSTALL-RETRY.md) 使用原目录。工具离线核对原失败堆栈及完整日志、归档原状态，连接后重新核对同一机身、完整原版程序和目标设置才写入；不手改阶段，不自动循环。其他 needs_review 仍按下条停止。本路径只经离线测试。
- `needs_review` 或未知USB操作结果：停止设备命令，保存阶段、日志和现有文件；不强行改状态、不补丁化绕过校验、不自动恢复或重新安装。
- `*_usb_unconfirmed`：退出码2，必须参照 [STATE-MACHINE.md](STATE-MACHINE.md) 和 [故障表](ADVANCED.md#本次遇到的错误怎么处理) 解释准确状态。只有工具已确认主体完成的特定结果才能按文档继续，不能把任意超时解释为成功。
- 保留用户已完成的工作。修复流程代码时，先做离线验证；不要把用户相机当作无限次试刷设备。

## 完成报告

明确写出：当前命令是否完成、实际状态、程序与参数核验是否通过、MSC是否正常返回、用户是否确认拍摄/回放，以及备份路径。

只报告实际测试过的功能。`verify`成功不等于首次备份/安装/恢复全部实测。未经额外授权不创建公开仓库、不推送机身文件、不向外发送日志；分享问题时先脱敏。
