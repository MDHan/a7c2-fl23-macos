# 开始安装时连接超时，如何重试

0.2.3 新增 `install --retry-service-entry`。它用于：备份和准备已完成，执行首次安装时提示 `UsbWaitTimeout: Expected USB identity did not appear: 0336`，原始堆栈明确停在 `MacSession.__enter__` 的 `wait_pid(0x0336, self.location)`，尚未进入安装主体。

**2026-10-21 已收到一例用户实机成功反馈：组合版重试安装完成，随后程序、参数和9处运行区域验证通过。** 见[验证记录](VALIDATION.md)。这不保证每台相机的连接超时都能解决；拍摄回放、预设调出和NTSC提示的人工结果尚未反馈。不要因为失败而连续运行。

## 怎么操作

1. 按 [README 的完整更新步骤](../README.md#已有工具如何更新)更新电脑上的工具到0.2.3或更新版本；其中包含进入工具文件夹、Git或ZIP旧目录的处理、环境更新及版本确认命令。保留原来的整个 `A7C2-work`，包括备份、错误文件及状态。不要重新 prepare，不删除或编辑记录。
2. 先确认相机当前显示海量存储/影像传输（MSC），无报错；如果仍显示服务模式、屏幕异常或连接结果未知，先停下核对。不要为满足这一条直接强制关机或取电池。
3. 没有其他相机操作运行时，在工具文件夹中查看现有记录和 Mac 识别的相机磁盘：

```sh
./a7c2-mac status --workspace "$HOME/Pictures/A7C2-work"
./a7c2-mac usb-status
```

状态应为 `needs_review`，`failed_action` 为 `install`，`failed_during` 为 `prepared`（或 `prepared_usb_unconfirmed`），错误恰为上述 `0336` 超时。没有识别到相机磁盘时先排查连接，不继续。

4. 确认相机仍为原版2.01、实际电量至少50%，明确选择重试后，复制整段并按提示输入当前电量：

```sh
(
  printf '相机当前实际电量（50–100，只输入数字）：'
  read -r A7C2_BATTERY
  sudo ./a7c2-mac install --workspace "$HOME/Pictures/A7C2-work" \
    --battery-percent "$A7C2_BATTERY" --retry-service-entry
)
```

`$HOME` 不用替换；只有实际使用了其他工作目录时才改完整路径。电量不能填示例值。

5. 看到 `RESULT: installed_pending_cold_start` 后，按 [README 的冷启动与验证](../README.md#冷启动与验证)操作。若主体完成但返回MSC超时，会显示对应的 `_usb_unconfirmed`，按 [状态说明](STATE-MACHINE.md)处理，不再安装。其他失败保留连接与文件，先核对新错误。

## 工具会核对什么

- 完整备份、候选内容和固定原版指纹，准备阶段只有备份和预检查，没有此前写入。
- 原始错误文件和完整日志互相对应；不会只凭状态里的错误文字放行，也不从多个失败中挑一个旧成功记录。
- 上次恰好停在等待服务身份前，退出日志没有服务退出命令或其他异常；准备结束的正常MSC或已知MSC等待超时须有记录。
- 重试前把原 `state.json` 另存至 `evidence/*-install-entry-retry-state.private.json`，记录哈希，不覆盖原备份或错误。
- 重试只尝试连接一次。先排除已有服务身份，再核对当前机身与备份一致及同一连接过程的物理端口，完整读回相机原版程序，核对目标设置，随后执行原有WBI预检查、安装、读回、保存设置及WBI收尾。

重试期间不会把 `needs_review` 手改成 `prepared`。再次遇到完全相同的入口超时，仍保留原失败阶段和每次报错，之后可以再次明确选择这一选项；没有后台重试。安装完整完成后才清除当前失败标识，历史记录继续保留。

## 哪些情况仍不允许

安装已经进入主体、程序或设置已写入、写入结果不明、服务认证失败、准备未完成、恢复或升级失败、其他错误、机身不匹配、记录缺失/有其他后续操作，都不适用。已有收尾尝试或诊断目录也需要另行核对。

该选项不解决 Issue #7 的恢复失败，也不替代 `finish-install`。不要改 `phase`、删错误文件或删尝试标记来满足检查。原始状态、备份和报错可能包含个人路径或机身信息，不要整包公开上传。
